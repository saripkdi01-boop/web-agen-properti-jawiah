# Website Personal Jawiah — Agen Properti SDP + Konsultan Salwa Tours

Website personal **Jawiah**: agen PT. Swarna Dwipa Property (Kendari) sekaligus
konsultan Salwa Tours untuk perjalanan ibadah umroh & haji.

- **Live:** https://jawiah.vercel.app/ (Vercel, deploy dari repo ini)
- **Repo:** https://github.com/saripkdi01-boop/web-agen-properti-jawiah

## Struktur
- `index.html` — website satu file (hasil export prototipe; aset inline)
- `README.md` — file ini
- `database/001-skema-agen-properti-travel.sql` — skema Supabase (agen, 7 produk
  properti, paket travel umroh/haji, testimoni, artikel, FAQ, leads) — untuk nanti

## Catatan
- Nomor WhatsApp masih nomor contoh (`6281234567890`, 1 baris konstanta
  `WA_NUMBER` di script) — ganti dengan nomor asli Bu Jawiah.
- Foto profil masih monogram "J" — ganti foto asli.
- Gambar kartu properti = ilustrasi suasana, bukan foto proyek.
- Harga belum dicantumkan (menunggu data resmi) — semua CTA mengarah ke WhatsApp.
